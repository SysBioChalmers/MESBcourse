# GEM3 — MICOM community modeling

Course data for the MICOM exercise in [MESB](https://github.com/SysBioChalmers/MESBcourse).

## Acknowledgements

The files in this folder are taken from the **2020 ISB Microbiome Course** (Part 2: *Modeling microbiota-wide metabolism with MICOM*), developed by the **[Gibbons Lab](https://github.com/Gibbons-Lab)** at the Institute for Systems Biology.

- Course materials: [gibbons-lab.github.io/isb_course_2020/micom](https://gibbons-lab.github.io/isb_course_2020/micom)
- Source repository: [github.com/Gibbons-Lab/isb_course_2020](https://github.com/Gibbons-Lab/isb_course_2020)

Included here:

- `metadata.tsv` — sample metadata (healthy vs recurrent *C. difficile* infection)
- `treasure_chest/` — QIIME 2 abundance and taxonomy tables from the course walkthrough

## MICOM software

Exercises use **[MICOM](https://github.com/micom-dev/micom)**. Please cite:

> Diener C, Gibbons SM, Resendis-Antonio O. MICOM: Metagenome-Scale Modeling To Infer Metabolic Interactions in the Gut Microbiota. *mSystems*. 2020;5(1):e00606-19.  
> https://doi.org/10.1128/mSystems.00606-19

Model database and growth medium used in the notebook are fetched from [Zenodo record 3755182](https://zenodo.org/record/3755182) (AGORA, western diet gut medium).
